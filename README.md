# Hu Taong 0.6

Pong, the Wangsheng Funeral Parlor way. Version 0.6, 14 March 2026.

Settings, fonts, music (8 tracks), sound effects and 12 backgrounds.

## Play it

The easiest way is **Toki Hub**, which installs any version with everything it needs.

From the source, with Python 3.12 and pygame 2.6.1:

```
pip install pygame==2.6.1
python main.py
```

## Build the .exe

```
pip install pyinstaller
pyinstaller main.spec
```

The .exe appears in `dist`.
