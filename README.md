# Hu Taong 0.3

Pong, the Wangsheng Funeral Parlor way. Version 0.3, 15 February 2026.

Tkinter, split into modules (app, game, objects).

## Play it

The easiest way is **Toki Hub**, which installs any version with everything it needs.

From the source, with Python 3 (Tkinter comes with the python.org installer):

```
python main.py
```

## Build the .exe

```
pip install pyinstaller
pyinstaller main.spec
```

The .exe appears in `dist`.
