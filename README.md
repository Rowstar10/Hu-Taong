# Hu Taong 0.1

Pong, the Wangsheng Funeral Parlor way. Version 0.1, 15 February 2026.

The first version: a single-file Tkinter game.

## Play it

The easiest way is **Toki Hub**, which installs any version with everything it needs.

From the source, with Python 3 (Tkinter comes with the python.org installer):

```
python HuTaong_Tkinter_v0.1.py
```

## Build the .exe

```
pip install pyinstaller
pyinstaller HuTaong_Tkinter_v0.1.spec
```

The .exe appears in `dist`.
