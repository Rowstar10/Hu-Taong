# Hu Taong 0.2

Pong, the Wangsheng Funeral Parlor way. Version 0.2, 15 February 2026.

Tkinter, still a single file, with small changes from 0.1.

## Play it

The easiest way is **Toki Hub**, which installs any version with everything it needs.

From the source, with Python 3 (Tkinter comes with the python.org installer):

```
python HuTaong_Tkinter_v0.2.py
```

## Build the .exe

```
pip install pyinstaller
pyinstaller HuTaong_Tkinter_v0.2.spec
```

The .exe appears in `dist`.
